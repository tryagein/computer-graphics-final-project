# Optional extension selection

After completing the baseline graphics, persistence, Agent, and Phase 6 quickstart checks, **directional-light shadow mapping** is the sole optional extension selected for a later iteration. It directly strengthens the OpenGL coursework content and builds on the existing directional-light path.

Phase 6 records the selection only. The current renderer still uses Blinn-Phong lighting without shadows. A future implementation would add a depth-map pass for one directional light, a configurable shadow toggle, bias/PCF controls, and a visual regression scene. Its acceptance gate should include the existing 100-object performance run so the extension cannot weaken the baseline.

No skybox, particles, screenshot-based Agent inspection, automatic camera correction, Undo/Redo, operation history, or multi-Agent roles are selected for this coursework delivery.
