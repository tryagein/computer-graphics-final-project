# 100-object performance result

Measured on 2026-11-01 (Asia/Shanghai) with the Visual Studio 2022 Debug build on Windows 11 Home (10.0.26200), AMD Ryzen 5 5600H, NVIDIA GeForce RTX 3050 Laptop GPU. The display was 1920×1080. OpenGL reported version `3.3.0 NVIDIA 595.97`; Windows reported display driver `32.0.15.9597` (2026-03-17).

| Measurement | Result |
| --- | ---: |
| Scene objects | 100 (50 cubes and 50 spheres) |
| Window / rendered viewport | 1280×720 / 628×580 |
| Camera motion | Automated continuous orbit around the scene |
| Duration | 60.0103 seconds |
| Frames sampled after 1-second warmup | 3,525 |
| Median frame rate | **60.0017 FPS** |
| Course target | ≥30 FPS — **pass** |

The benchmark runs the full editor UI, scene renderer, and buffer swap on each frame. VSync is enabled; `glFinish` waits for GPU work before the swap. It records the median of per-frame rates after a one-second warmup. The measured rate is near the display's 60 Hz VSync limit, so it does not estimate the maximum uncapped rendering rate. Camera movement is scripted for repeatability rather than generated by manual keyboard input.

Reproduce after building `scene_editor`:

```powershell
& '.\build-vs\Debug\scene_editor.exe' --benchmark 60
```

The benchmark exits with code 0 if its median is at least 30 FPS, code 2 if it is below the target. Actual results depend on GPU, driver, resolution, active power profile, and other workloads.
